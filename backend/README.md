# Ingest API (Backend)

## Setup
```
pip install -r requirements.txt
```

## Run
```
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
`--host 0.0.0.0` makes it reachable from other machines on your lab network (e.g. `192.168.50.x`), not just `localhost` — needed later for Option B when Person B's detection engine or your VMs need to reach it remotely.

Interactive API docs (auto-generated by FastAPI): http://127.0.0.1:8000/docs

## Files
- `database.py` — SQLite engine/session setup
- `models.py` — SQLAlchemy tables: `hosts`, `artifacts`
- `schemas.py` — Pydantic request/response shapes
- `main.py` — the FastAPI app itself, all endpoints
- `push_samples.py` — utility to push a `sample_data/<date>_<hostname>/` folder to a running API

## Endpoints
- `GET /health` — liveness check
- `POST /ingest` — accepts a JSON array of artifacts (i.e. the exact content of one collector output file like `processes.json`)
- `GET /artifacts?host=...&artifact_type=...&limit=...` — query stored artifacts
- `GET /hosts` — list all hosts that have reported in

## Pushing your collected sample data in
```
python push_samples.py ../sample_data/2026-07-29_win10-vm01
```
This posts every `*.json` file in that folder to `/ingest`, one file (one artifact type) at a time.

## Verifying it worked
```
curl http://127.0.0.1:8000/hosts
curl "http://127.0.0.1:8000/artifacts?limit=5"
```
Or just open http://127.0.0.1:8000/docs in a browser and use the interactive "Try it out" buttons.
